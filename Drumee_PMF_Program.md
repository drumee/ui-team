# **Scoring Model & Analysis Framework**

## **Global PMF Score**

Primary metric: % of respondents who answered 'Very Disappointed' to Q4 (Sean Ellis score).

| Score | Interpretation | Action |
| :---- | :---- | :---- |
| **≥ 40%** | Strong PMF signal | Accelerate: scale distribution, prep self-host launch |
| **25–39%** | Partial PMF — iterate | Fix top friction (Q6 tags) before scaling. Re-survey in 30 days. |
| **\< 25%** | PMF not reached | Stop scaling. Run 10 user interviews. Rebuild aha moment flow. |

## **Secondary Signal Scoring**

| Signal | How to measure | Strong signal threshold |
| :---- | :---- | :---- |
| **Clarity (Q1)** | % of responses coded as CLEAR vs UNCLEAR | ≥ 60% CLEAR |
| **Aha Moment (Q2)** | % who selected 'Yes — it clicked clearly' | ≥ 50% |
| **Retention Intent (Q7)** | % selecting 'Keep using' \+ 'Would pay' | ≥ 40% on both |
| **Self-host signal (Q7)** | % selecting 'I want to self-host' | ≥ 20% \= sovereign ICP confirmed |
| **Top value pillar (Q5)** | Tag frequency by pillar across all responses | 1 pillar ≥ 40% \= messaging angle |
| **Wishlist (Q8)** | Tag frequency mapped to roadmap pillars | Top 2 tags \= sprint input |
